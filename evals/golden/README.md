# Golden sets

Versioned case files: `v{N}/cases.jsonl` (format in [evaluation spec §2](/docs/specs/evaluation.md#2-golden-set-format-and-graders),
JSON Schema in [`case.schema.json`](case.schema.json), generated by `cohortex-eval validate --write-schema`).
A case enters the CI gate only after Siddharth sets `reviewed_by`; see
[`v1/README.md`](v1/README.md) for the review steps.
